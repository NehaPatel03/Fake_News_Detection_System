# Fake_News_Detection_System
Dataset link : https://www.kaggle.com/c/fake-news/data?select=train.csv
Fake news has become a significant issue in the digital age, affecting public perception and the flow of information. This project aims to build a machine learning model that detects fake news articles by analyzing their text. Using natural language processing (NLP) and machine learning techniques, the project classifies news articles into two categories: fake and real. By doing so, it helps combat misinformation and promotes the dissemination of accurate news.
